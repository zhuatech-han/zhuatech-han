## 如何开始合作

1. **说明业务问题**：希望解决什么问题，目前有哪些系统或资料。
2. **明确首期范围**：讨论可行方案、交付内容、时间和预算依据。
3. **分阶段开发与验证**：按里程碑推进开发、测试和反馈。
4. **部署与交接**：按约定交付源码、文档、部署资料和维护说明。

不必先准备完整需求书。带着一个具体场景，就可以开始沟通。
